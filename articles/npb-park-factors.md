## はじめに

「バンテリンドームは投手天国」「神宮は打者有利」——野球ファンなら感覚的に知っていること。でも、それを**数値で証明**したことはあるでしょうか。

NPBの12球場はサイズも天然芝の有無も照明も全然違います。ホームランが出やすい球場もあれば、フライが犠牲フライになる球場もある。これを無視して「阪神の投手陣はすごい」と言っても、それは球場の力かもしれない。

今回は2016〜2025年の8,619試合スコアから**パークファクター（PF）**を計算し、12球団の年度推移を可視化しました。さらに、改修工事がPFをどう変えたかも分析します。

→ **GitHub**: https://github.com/yasumorishima/npb-prediction

## パークファクターとは

パークファクターは「この球場で試合すると、どれだけ得点が増えるか/減るか」を表す指標です。

### 計算式（Baseball Reference標準）

$$
\text{PF} = \frac{(\text{ホーム得点} + \text{ホーム失点}) / \text{ホーム試合数}}{(\text{アウェイ得点} + \text{アウェイ失点}) / \text{アウェイ試合数}}
$$

- **PF > 1.00**: 打者有利（点が入りやすい球場）
- **PF = 1.00**: 中立
- **PF < 1.00**: 投手有利（点が入りにくい球場）

### なぜ「ホーム得点だけ」ではダメか

```
❌ PF（雑）= ホーム得点 / 平均得点
```

これだと**チームの打力の差**が混入します。攻撃力の高いチームがホームで戦えば、球場に関係なく数字が高くなる。

```
✅ PF（正）= ホーム試合の得失点効率 / アウェイ試合の得失点効率
```

「ホームとアウェイで、同じチームがどれだけ違う環境で戦っているか」を見ることで、**球場の純粋な影響**だけを取り出せます。

### FanGraphs方式（5年平均）の意味

1年のデータだけだと乱数の影響が大きい（特にHRは少ないサンプルで振れやすい）。そこで一般的には**3〜5年の合算データ**を使います。今回は5年平均（PF_5yr）も計算し、折れ線グラフで表示しています。

## データ取得

npb.jp の試合スコアを `requests` + `BeautifulSoup` でスクレイピングし、試合ごとに「ホームチーム・得点・球場名」を記録しました。

```python
# fetch_npb_games.py（抜粋）
import requests
from bs4 import BeautifulSoup

url = f"https://npb.jp/scores/{year}/index.html"
res = requests.get(url, timeout=10)
res.encoding = "utf-8"  # ← ここ重要
```

:::message
**requestsのUTF-8罠**: npb.jpのHTMLは `charset=UTF-8` を明示していますが、レスポンスの `encoding` を手動で指定しないと `apparent_encoding`（Shift-JIS推定）に引っ張られて文字化けします。必ず `res.encoding = "utf-8"` を指定してください。
:::

## 5年平均の落とし穴：改修をまたいだデータは意味を失う

PF_5yr には重大な問題があります。

**例：バンテリンドーム（中日）**

2025年のPF_5yr（5年平均）は0.844。ところが、2026年にHRウイング設置（左右中間▲6m、フェンス高▲1.2m）が予定されています。もし改修後も5年前のデータを混ぜ続けたら、**2030年頃まで実態より低いPFが表示され続けてしまう**。

これを避けるため、コードでは改修年以降のデータのみを使う「改修ブレイクポイント」を実装しています。

```python
# calc_park_factors.py（抜粋）
RENOVATION_BREAKS: dict[str, list[int]] = {

    "日本ハム":     [2023],        # エスコンフィールド移転
    "楽天":         [2016, 2026],  # 2016: 天然芝化 / 2026: フェンス前方移設
    "中日":         [2026],        # HRウイング設置
}

def calc_multiyear_pf(games, team, year, window=5):
```

## 注目球場の考察

### ① PayPayドーム（ソフトバンク）── 2015年HRテラスで劇的変化

2015年のHRテラス設置（左右中間▲6m、フェンス高さ▲1.64m）は球場を一変させました。データが揃う2016年からのPF_5yr推移を見ると：

| 年度 | PF | PF_5yr |
|---|---|---|
| 2016 | 1.171 | 1.171 |
| 2017 | 0.919 | 1.036 |
| 2018 | 0.969 | 1.009 |
| 2024 | 1.002 | 0.996 |
| 2025 | 0.976 | 1.007 |

改修直後の2016年はPF=1.171と打者有利が目立ちましたが、10年かけて**PF≈1.00の中立的な球場**に収束しています。

### ② ZOZOマリン（ロッテ）── 2019年HRラグーンで急変

2019年のHRラグーン設置（左右中間▲4m）の前後で数値が変わります：

| 年度 | PF | 備考 |
|---|---|---|
| 2018 | 0.874 | 改修前（投手天国） |
| 2019 | 0.923 | 改修年 |
| 2020 | 1.101 | 翌年、急上昇 |
| 2021 | 1.235 | 打者有利に |

改修翌年（2020年）から打者有利に転じ、2021年は1.235まで急上昇。フェンス変更が即座に数字に表れた好例です。

### ③ エスコンフィールド（日本ハム）── 新球場は2年かけて本領発揮

2023年に札幌ドームからエスコンフィールドへ移転。最初の年（2023）は右中間が広いためかPF=0.969と投手有利でしたが、翌2024年はPF=1.212と急上昇。2年目（2025）もPF=1.271と高水準を維持しています。

| 年度 | PF | PF_5yr |
|---|---|---|
| 2022（札幌ドーム） | 0.949 | 0.967 |
| 2023（エスコン1年目） | 0.969 | 0.969 |
| 2024（エスコン2年目） | 1.212 | 1.089 |
| 2025（エスコン3年目） | 1.271 | 1.147 |

新球場は選手がコースを把握するまで時間がかかる、という見方もできます。

### ④ バンテリンドーム（中日）── 10年間の投手天国、2026年に変わるか

10年間（2016〜2025）のPFを並べると：

| 年度 | PF | PF_5yr |
|---|---|---|
| 2016 | 0.773 | 0.773 |
| 2017 | 0.866 | 0.819 |
| 2019 | 0.880 | 0.825 |
| 2022 | 0.867 | 0.839 |
| 2025 | 0.955 | 0.844 |

10年間を通じてPF_5yr=0.773〜0.955の範囲に収まる投手天国。2025年はやや改善していますが、それでも平均より1割以上点が入りにくい球場です。

2026年にHRウイング設置（左右中間▲6m、フェンス高▲1.2m）が予定されており、ZOZOマリンと同様の急変があるかもしれません。

### ⑤ 楽天モバイルパーク（楽天）── 2回の改修、2026年が本命

楽天は2016年の天然芝化・左中間フェンス低下に加え、2026年にもフェンス前方移設が予定されています。

| 年度 | PF | PF_5yr | 備考 |
|---|---|---|---|
| 2016 | 1.072 | 1.072 | 天然芝化 |
| 2019 | 0.839 | 1.011 | 落ち込み |
| 2023 | 0.841 | 0.939 | 投手有利傾向 |
| 2024 | 0.814 | 0.937 | 低下 |
| 2025 | 0.931 | 0.908 | ← PF_5yr=0.908 |

5年平均は2016年改修の影響が薄れ、近年は0.9前後の投手有利。2026年のフェンス変更でどう変わるか注目です。

## 2026年展望

2026年に大きな変化が予定されているのが**バンテリンドームと楽天モバイルパーク**の2球場。

- **バンテリン**: HRウイング設置。10年間の投手天国から打者有利への転換が予想されます
- **楽天**: フェンス前方移設。現在PF_5yr=0.908の投手有利から中立〜打者有利への変化が見込まれます

この2球場の変化は、**中日と楽天の投手陣の「数字の見え方」に直接影響**します。防御率が上がってもそれは投手の劣化ではなく球場変更かもしれません。PFを考慮して評価するかどうかで、選手の評価が変わってきます。

また、**東京ドーム（巨人）** はPF_5yr=1.008（2025年）とほぼ中立に収束しています。かつては「ドーム有利」と言われましたが、現代野球では球場効果は薄まっています。
