## きっかけ

Baseball Savant で投手の球種ごとの成績を眺めていて、ふと気になったことがあります。「ある年によく空振りを取れていた球種は、翌年も取れているのだろうか」「ある年によく抑えた球種は、翌年もよく抑えているのだろうか」。

ある年の数字が良かったのは、その球種が本当に良いからなのか、たまたまそういう年だったからなのか。指標によって、そのあたりの事情は違いそうです。そこで、MLB の公開データで次のことを調べてみました。

> ある投手のある球種について、今年の成績と翌年の成績（同じ投手・同じ球種）には、どれくらい関係があるか。
> その関係の強さは、指標（空振り率、run value など）によってどれくらい違うか。

私は野球の現場の経験者ではなく、公開データを集計してみただけです。そのつもりで読んでいただければと思います。

## 使った指標

Baseball Savant（MLB の Statcast データを公開しているサイト）には、投手ごと・球種ごとに次のような数字が載っています。今回はこのうち 5 つを主に見ました。

| 指標 | 意味 |
|---|---|
| 使用率 | その投手が投げた球のうち、その球種が占める割合 |
| 空振り率 | 打者がスイングした球のうち、空振りだった割合 |
| 被 xwOBA | その球種で終わった打席の結果を、出塁・長打の価値で表したもの。打球については、実際にヒットになったかどうかではなく、主に打球の速さと角度から見た期待値に置き換えている（一部の打球では打者の走力も使う。三振・四球などはそのまま） |
| 強い打球の割合 | 打たれた打球のうち、打球速度が 95 マイル（約 153 km/h）以上だった割合 |
| run value / 100 球 | その球種を投げた結果、失点をどれだけ防いだか（あるいは増やしたか）を点数に換算し、100 球あたりにしたもの。ストライク・ボール、ヒット・アウトなど 1 球ごとの結果に付けた値を足し合わせている。今回のデータでは値が大きいほど投手にとって良い |

run value は球種の成績を 1 つの数字にまとめたものなので、目にする機会が多い数字だと思います。後半では、この run value を 1 球ごとのデータまで降りて調べてみました。

## 調べ方

### 翌年との相関を見る

同じ投手・同じ球種の、連続する 2 シーズンを 1 組にします。たとえば「ある投手のスライダーの 2023 年」と「同じ投手のスライダーの 2024 年」で 1 組です。こうした組をたくさん集めて、1 年目の値と 2 年目の値の相関を取りました。

- 相関が 1 に近い：今年良かった球種は、翌年もだいたい同じくらい良い
- 相関が 0 に近い：今年良かったかどうかと、翌年の成績にはほとんど関係がない

### 球種ごとの平均を引いてから比べる

スライダーはもともと空振りが多く、シンカーは少ない、というように、球種によって数字の水準がかなり違います。そのまま相関を取ると、「スライダーはどの投手が投げても空振りが多い」という球種の違いだけで相関が高く出てしまいます。

見たいのは「スライダーの中で、この投手のスライダーは良いほうか」が翌年も続くかどうかなので、その年のその球種の平均を引いた値（たとえば「スライダー全体の平均より空振り率が何ポイント高いか」）で相関を取りました。

### 球数で分ける

投げた球数が少ないと、数字は偶然でぶれやすくなります。そこで組を、2 シーズンのうち少ないほうの球数で 4 つの帯に分けました。目安として、100〜199 球は中継ぎ投手の 3 番目の球種くらい、800 球以上は先発投手の主な球種くらいの量だと思います。

### データ

- Baseball Savant の球種別成績、2017〜2025 年。自分で公開しているデータセット（Hugging Face `yasumorishima/mlb-stats` の `marts/mart_scouting_reliability`）から計算しました
- どちらの年も 100 球以上投げた組だけを使い、全部で 8,022 組です
- 進行中の 2026 年は入れていません

## 結果

結果を図と表にまとめました。

![同じ投手・同じ球種の翌年との相関](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_metric_yoy_ja.png)

| 指標 | 100〜199 球 | 200〜399 球 | 400〜799 球 | 800 球以上 |
|---|---|---|---|---|
| 使用率 | 0.79 | 0.81 | 0.87 | 0.84 |
| 空振り率 | 0.53 | 0.63 | 0.70 | 0.74 |
| 被 xwOBA | 0.26 | 0.34 | 0.46 | 0.53 |
| 強い打球の割合 | 0.20 | 0.28 | 0.38 | 0.43 |
| run value / 100 球 | 0.09 | 0.17 | 0.25 | 0.35 |
| 組の数 | 3,063 | 2,997 | 1,561 | 401 |

気づいたことを書いておきます。

- 使用率を除くと、どの指標も球数が多いほど翌年との相関が高くなりました。球数が少ないほど偶然のぶれが大きいので、ここは予想どおりでした
- 指標による違いは、球数による違いよりも大きく出ました。100〜199 球の組の空振り率（0.53）のほうが、800 球以上の組の run value（0.35）より翌年との相関が高くなっています
- run value は、800 球以上の組でも 0.35 でした。今回のデータでは、今年の run value と翌年の run value の関係は弱い、という結果です

使用率の相関が高いのは、投手が球種の配分を年ごとに大きく変えないためだと思われます。良し悪しの指標ではないので、参考として載せています。

### 上位 20% が翌年も上位 20% に入る割合

相関の数字だけだとイメージしにくかったので、別の形でも数えてみました。球種の平均を引いた値を各年の中で並べ、良いほうから数えて上位 20% に入った球種が、翌年も上位 20% に入っていた割合です（被 xwOBA は低いほど良いとして並べています）。今年と翌年がまったく無関係なら、この割合は 20% くらいになるはずです。

| 指標 | 100 球以上の全組 | 400 球以上の組 |
|---|---|---|
| 空振り率 | 52% | 58% |
| 被 xwOBA | 37% | 41% |
| run value / 100 球 | 29% | 32% |

400 球以上の組で見ると、run value で上位 20% に入った球種のうち、翌年も上位 20% だったのは 3 つに 1 つくらいで、36% は翌年に下半分まで下がっていました（今年と翌年が無関係なら 50% くらいです）。空振り率では、翌年も上位 20% だったのが 58%、下半分まで下がったのは 12% でした。

## run value をもう少し調べる

run value の翌年との相関が低いのはなぜなのか、1 球ごとのデータまで降りて調べてみました。

### run value の計算方法を確かめる

[MLB の用語解説](https://www.mlb.com/glossary/statcast/run-value)によると、run value は 1 球ごとに、その球の結果（ボール、ストライク、ヒット、アウトなど）が得点の見込みをどれだけ動かしたかで値を付け、それを足し合わせたものです。

実際に確かめるため、Baseball Savant から 2017〜2025 年のレギュラーシーズンの投球データ（約 598 万球）を 1 球ずつ取得しました。各球には、その球で得点の見込みがどれだけ動いたかを表す値（`delta_run_exp`、打者に有利なほどプラス）が付いています。これを投手・球種・年ごとに足し、投手側から見るため符号を反対にして整数に丸めると、Savant が公開している球種別の run value と、どの年も 99.2〜99.7% の行でぴったり一致しました。一致しなかった行も差は 1 で、どれも小数点以下がほぼ 0.5 の値（丸め方で結果が変わる値）でした。なお、Savant の球種別の表ではナックルカーブとスローカーブがカーブにまとめられているので、こちらもそれに合わせています。

ここで分かったのは、球種別の run value には、そのときの走者やアウトの状況も入っているということです。同じ空振りでも、場面によって値が違います。たとえば 2025 年の、無死・カウント 0-0 からの空振りは、走者なしでは平均 0.039 点、満塁では平均 0.045 点ぶん投手に有利な値になっていました。

### run value を 5 つに分ける

1 球ごとの値を、次の 5 つに分けました。5 つを足すと、元の run value にぴったり戻るように作っています。

| 部分 | 中身 |
|---|---|
| 打席の途中の球 | 打席が終わらなかった球（ボール、見逃し・空振りのストライク、ファウル）で、カウントが変わったことによる分（2 ストライク後のファウルは 0） |
| 三振・四死球 | 三振、四球、死球で打席が終わった分 |
| 打球（質） | 打たれた打球の分のうち、打球の速さと角度（被 xwOBA）と、打ったときのカウントから見込まれる分 |
| 打球（運） | 打たれた打球の分のうち、実際の結果と見込みの差。同じ打球でも、野手の正面に飛んでアウトになるか、間を抜けてヒットになるかで生まれる差 |
| 状況 | 同じカウント・同じ結果でも、走者やアウトの状況によって値が変わる分 |

「状況」以外の 4 つは、走者やアウトの状況をならした値で計算しています。具体的には、その年・そのカウント・その結果の全球の平均を使い、打球の質は、その年・同じカウントで打球の速さと角度が似ている打球の平均を使っています。

### 分けてみた結果

2 シーズンとも 400 球以上投げた組（1,962 組）で見ると、次のようになりました。前半と同じく、100 球あたりの値で、球種ごとの平均を引いてから計算しています。

| 部分 | 1 年の run value のばらつきに占める割合 | 翌年との相関 | 翌年に続く分への寄与 |
|---|---|---|---|
| 打球（質） | 36% | 0.27 | 37% |
| 打球（運） | 27% | 0.06 | −7% |
| 三振・四死球 | 22% | 0.57 | 47% |
| 打席の途中の球 | 11% | 0.60 | 25% |
| 状況 | 4% | −0.03 | −2% |
| run value 全体 | 100% | 0.27 | 100% |

表の見方を補足します。

- 「1 年の run value のばらつきに占める割合」：投手・球種によって run value は大きく違います。その違いを 5 つの部分に分けたときの、それぞれの取り分です
- 「翌年との相関」：その部分だけを取り出して、今年と翌年の相関を取ったものです
- 「翌年に続く分への寄与」：「今年の run value が高い球種は、翌年も高い」という結びつき（統計でいう、今年と翌年の run value の共分散）を、今年の 5 つの部分に分けたときの取り分です。マイナスは、その部分が結びつきをかえって弱める向きに働いていることを表します。これは今年の部分と翌年の run value 全体との関係で計算しているので、「翌年との相関」とは符号が一致しないことがあります（打球の運がその例です）

割合と寄与は、どちらも 5 つを足すと 100% になります。run value 全体の翌年との相関 0.27 は、400 球以上の組をまとめて計算しているので、前半の帯ごとの表の値（400〜799 球 0.25、800 球以上 0.35）とは少し違います。

読み取れることを書いておきます。

- 1 年の run value のばらつきのうち、3 割ほど（運 27% と状況 4%）は、翌年にほとんど続かない部分でした
- 翌年に続く分の 7 割ほど（47% と 25%）は、三振・四死球と打席の途中の球から来ています。この 2 つは、1 年のばらつきの中では合わせて 3 割ほどしかありません
- 打球の質の部分も、翌年との相関は 0.27 と高くありませんでした

1 年の run value は、翌年に続きやすい部分と続きにくい部分が混ざった数字になっている、ということだと思います。

### 続く部分だけで翌年を当ててみる

それなら、続きにくい 2 つ（運と状況）を除いた残りの 3 つを足せば、翌年の run value をよりよく当てられるのではないか、と考えて試してみました。当てる式（重みを付ける場合はその重み）は 2 年目が 2021 年までの組で決め、2 年目が 2022 年以降の組で確かめています（式を決めるのに使っていない年で確かめるためです）。そのため、下の表の run value の 0.29 は、上の表の 0.27（全部の年の組）とは少し違います。

| 今年の数字 | 翌年の run value との相関（400 球以上） |
|---|---|
| run value | 0.29 |
| 運と状況を除いた 3 つの和 | 0.35 |
| 3 つにそれぞれ重みを付けたもの | 0.38 |

運と状況を除いて足しただけで、今年の run value をそのまま使うより翌年との相関が高くなりました。投手を単位に組を無作為に選び直して計算することを 2,000 回くり返すと、この差（0.35 と 0.29 の差）の 95% 区間は 0.03〜0.10 で、0 を含みませんでした。100〜399 球の組でも同じ向き（0.12 → 0.18）でしたが、どちらも低い値です。

## まとめ

今回のデータでは、次のような結果になりました。

- 空振り率は、翌年との相関が比較的高くなりました
- run value は、1 年分だと翌年との相関が低くなりました
- run value を 5 つに分けると、1 年のばらつきの 3 割ほどは、打球の運と走者・アウトの状況という、翌年にほとんど続かない部分でした
- 翌年に続く分の 7 割ほどは、三振・四死球と打席の途中の球から来ていました
- 運と状況を除いた 3 つを足すと、今年の run value そのものより翌年の run value との相関が高くなりました（400 球以上・2 年目が 2022 年以降の組で 0.29 → 0.35）

1 年分の run value を見るときは、空振り率や三振・四死球のような翌年に続きやすい数字も一緒に見ると、翌年の見込みを考えやすくなりそうだ、というのが個人的な感想です。

## 注意点

- 相関には「数字の偶然のぶれ」と「球種そのものが変わった（握りを変えた、球速が落ちた等）」の両方が入っています。1 シーズンの数字がどれだけ正確かを表すものではありません
- 800 球以上の組は 401 組と少なめです
- 球数は 2 シーズンのうち少ないほうで分けているので、同じ帯の中に片方の年だけ多く投げている組も混ざります。また、帯によって先発と中継ぎの割合なども違うので、帯の間の差には球数以外の違いも入っています
- 2020 年（60 試合の短縮シーズン）を含む組も入れています
- 成績が落ちて翌年に登板しなくなった（または 100 球未満になった）投手は組になりません。この偏りは補正していません
- 「打球（運）」は、打球の速さと角度、カウントから見込まれる値との差として計算しただけで、守備や球場の影響などを分けてはいません
- 5 つへの分け方は、今回自分で決めたものです。たとえば打球の見込みにカウントを使うかどうかで、「質」と「運」の境目は少し動きます
