Baseball Savant で投手の球種ごとの成績を眺めていて、ふと気になったことがあります。「ある年によく空振りを取れていた球種は、翌年も取れているのだろうか」「ある年によく抑えた球種は、翌年もよく抑えているのだろうか」。

ある年の数字が良かったのは、その球種が本当に良いからなのか、たまたまそういう年だったからなのか。指標によって事情は違いそうなので、MLB の公開データで調べてみました。私は野球の現場の経験者ではなく、公開データを集計してみただけです。

## 使ったデータと、比べ方

- **球種別の成績**：Baseball Savant の Pitch Arsenal（投手 × 球種 × 年の表）、2017〜2025 年
- **1 球ごとのデータ**：Savant の Statcast Search から取得した約 598 万球（run value を分けるときに使います）

比べ方は単純で、**同じ投手・同じ球種の、連続する 2 シーズンを 1 組**にして、1 年目と 2 年目の相関を取ります。たとえば「ある投手のスライダーの 2023 年」と「同じ投手のスライダーの 2024 年」で 1 組です。どちらの年も 100 球以上投げた組だけを使い、全部で **8,022 組**になりました。

そのまま比べると、「スライダーはどの投手が投げても空振りが多い」という球種の違いだけで相関が高く出てしまいます。見たいのは「スライダーの中で、この投手のスライダーは良いほうか」なので、**その年・その球種の平均を引いた値**で相関を取りました。

組の作り方は、SQL だとこうなります。説明用に簡略化したもので、実際は dbt のモデル（`mart_scouting_reliability`）として、進行中のシーズンを除くなどの処理も入れて書いています。

```sql
with a as (
    select player_id, season, pitch_type, pitches, whiff_rate,
           whiff_rate - avg(whiff_rate) over (partition by season, pitch_type) as w
    from pitch_arsenal
    where pitches >= 100
)
select least(x.pitches, y.pitches) as min_pitches, x.w as w1, y.w as w2
from a x
join a y on y.player_id = x.player_id
        and y.pitch_type = x.pitch_type
        and y.season = x.season + 1
```

投げた球数が少ないと数字は偶然でぶれやすいので、組を **2 シーズンのうち少ないほうの球数** で 4 つの帯に分けて、帯ごとに `corr(w1, w2)` を出しています。

## 空振り率は翌年も続き、run value は続きにくい

![空振り率は翌年も続き、run value は続きにくい](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_1_ja.png)

どの指標も球数が多いほど相関が上がりますが、**指標による違いのほうが、球数による違いより大きく出ました**。100〜199 球の組の空振り率（0.53）のほうが、800 球以上の組の run value（0.35）より高くなっています。

2 シーズンとも 400 球以上投げた 1,962 組で見ると、翌年との相関は空振り率が 0.70、run value が 0.27 です。この 2 つがどのくらい違うのか、組を 1 点ずつ打つとこうなります。

![相関 0.70 と 0.27 の違い](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_6_ja.png)

空振り率は、1 年目に平均より上だった球種の多くが 2 年目も上にいて、点が右上がりの帯になっています。run value は、1 年目に平均より上でも 2 年目は上下にばらけていて、形としてはほとんど丸い雲です。

## 上位の球種が、翌年も上位に残る割合

相関の数字だけだとイメージしにくいので、別の数え方もしてみました。球種の平均を引いた値を各年の中で並べ、上位 20% に入った球種が翌年も上位 20% に入っていた割合です。今年と翌年がまったく無関係なら 20% くらいになるはずです。

![上位 20% の球種が、翌年も上位 20% に残る割合](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_2_ja.png)

400 球以上の組で、run value の上位 20% だった球種のうち、翌年も上位 20% だったのは 3 つに 1 つくらいでした。36% は翌年に下半分まで下がっています（無関係なら 50% くらい）。空振り率では、下半分まで下がったのは 12% でした。

## 500 球投げたときの翌年との相関は、空振り率 0.68、run value 0.20

1 年の数字を「その投手・その球種の実力 ＋ 偶然のぶれ」と考えると、n 球投げたときに実力が占める割合はだいたい `n / (n + k)` の形になります。k は、ちょうど半分が実力・半分が偶然になる球数です。ここでの「実力」は、偶然でない部分という意味です。

さらに実力そのものも年によって少し変わるので、その変わりにくさを c（1 以下）とすると、翌年との相関は「c × 1 年目の実力の割合と 2 年目の実力の割合の平均（幾何平均）」になります。

この考え方は、DEV.to に英語版を載せたときにコメントで教えていただき、その後、k ではなく「決まった球数での相関」で見るという見せ方も提案していただきました。8,022 組を球数の順に 12 のグループに等分し、グループごとの相関と、グループに入っている組の実際の球数から、次の式に一番よく合う c と k を探しました（グループの組の数で重みを付けています）。そのうえで、2 シーズンとも同じ n 球を投げたときの相関 `c × n / (n + k)` を計算しています。

```python
# あるグループ（2 シーズンの球数が n1, n2 の組の集まり）で予想される相関
r_pred = c * np.mean(np.sqrt(n1 / (n1 + k) * n2 / (n2 + k)))
# 2 シーズンとも n 球投げたときの相関
r_n = c * n / (n + k)
```

![500 球投げたときの翌年との相関](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_8_ja.png)

- 空振り率は **0.68**（投手単位で組を選び直して 200 回計算した 95% 区間は 0.65〜0.70）
- 被 xwOBA は 0.41（0.38〜0.44）
- run value は **0.20**（0.18〜0.23）

500 球は、救援投手の主な球種や、先発投手の 2 番目の球種の 1 シーズン分に近い球数です（2021〜2025 年の中央値で、40 回以上投げた救援投手のいちばん多い球種が 463 球、100 回以上投げた先発投手の 2 番目の球種が 613 球）。先発投手の主な球種を 1 シーズン投げると約 1,100 球になります（2021〜2025 年に 1 シーズン 2,400 球以上投げた投手の、いちばん多く投げた球種 316 件の中央値は 1,086.5 球）。そこまで投げても run value は 0.35（0.27〜0.39）で、倍以上の球数でも、500 球の空振り率（0.68）の半分ほどです。

半分が実力になる球数 k で言うと、空振り率は約 100 球（76〜138 球）、被 xwOBA は約 300 球（176〜498 球）です。run value は約 1,800 球と出ますが、区間は 455〜2,212 球と広く、選び直した 200 回のうち 92 回は c が上限の 1 に張り付きました。今回のデータにある球数の範囲（1 球種 1 年で多くても 2,300 球ほど）では c と k を分けきれないためです。一方、データによく合う (c, k) の組なら、データにある球数の範囲ではほぼ同じ曲線を描くので、決まった球数での相関は区間が k よりずっと狭く出ます（500 球で 0.18〜0.23、約 1,100 球で 0.27〜0.39）。前の版では k を中心に書き、run value の k を「少なくとも 600 球」としていましたが、選び直しの回数を 200 回に増やして計算し直すと下限は 455 球でした。

コメントでは run value の k は 700 球ほどと見積もられていました。帯は 2 シーズンのうち少ないほうの球数で分けているので、もう片方の年はそれより多く投げています。その球数まで入れて当てはめると、k は大きめに出ます。

## run value の中身を分けてみる

run value が続きにくいのはなぜなのか、1 球ごとのデータまで降りて調べました。

[MLB の用語解説](https://www.mlb.com/glossary/statcast/run-value)によると、run value は 1 球ごとに、その球の結果（ボール、ストライク、ヒット、アウトなど）が得点の見込みをどれだけ動かしたかを足し合わせたものです。1 球ごとのデータには、その値が `delta_run_exp`（打者に有利なほどプラス）として入っています。これを投手・球種・年ごとに足して符号を反対にし、整数に丸めると、Savant が公開している球種別の run value と、**どの年も 99.2〜99.7% の行でぴったり一致しました**。一致しなかった行も差は 1 で、どれも小数点以下がほぼ 0.5 の値（丸め方で結果が変わる値）でした。

そのうえで、1 球ごとの値を次の 5 つに分けました。5 つを足すと、元の run value にぴったり戻るように作っています。

- **打席途中の球**：打席が終わらなかった球（ボール、ストライク、ファウル）で、カウントが変わった分
- **三振・四死球**：三振、四球、死球で打席が終わった分
- **打球の質**：打たれた打球のうち、打球の速さと角度（xwOBA）とカウントから見込まれる分
- **打球の運**：打たれた打球の、実際の結果と見込みの差。同じ打球が野手の正面に飛んでアウトになるか、間を抜けてヒットになるかの差
- **走者・アウトの状況**：同じカウント・同じ結果でも、走者やアウトの状況で値が変わる分

「状況」以外の 4 つは、走者やアウトの状況をならした値です。その年・そのカウント・その結果の全球の平均を使い、打球の質は、同じ年・同じカウントで xwOBA が近い（0.05 刻み）打球の平均を使っています。「結果」は、打席が終わった球ならその結果（三振、単打など）、終わらなかった球なら球の判定（ボール、空振りなど）です。

中心の部分だけ抜き出すとこうなります（簡略版です。xwOBA が付いていない打球の扱いや、最後に投手側から見るため符号を反対にする処理などは省いています）。

```python
# その年・カウント・結果ごとの平均 = 走者とアウトをならした値
P["cn"] = P.groupby(["season", "balls", "strikes", "result"]).delta_run_exp.transform("mean")
# 打球は、同じ年・カウント・xwOBA の刻みの平均が「見込み」
P["cn_exp"] = P[bip].groupby(["season", "balls", "strikes", "xwoba_bin"]).cn.transform("mean")

P["midpa"]     = np.where(~end_of_pa, P.cn, 0)          # 打席途中の球
P["pa_nonbip"] = np.where(end_of_pa & ~bip, P.cn, 0)    # 三振・四死球
P["bip_exp"]   = np.where(bip, P.cn_exp, 0)             # 打球の質
P["bip_luck"]  = np.where(bip, P.cn - P.cn_exp, 0)      # 打球の運
P["situation"] = P.delta_run_exp - P.cn                 # 走者・アウトの状況
```

### 1 つの球種で見ると

分けると何が見えるのか、同じ 2021 年に run value が上位だった球種から、中身の違いが分かりやすい 2 つを選んで、翌年の 2022 年と並べてみます。ここの数字は 1 年の合計（点）で、球種の平均は引いていません。

![同じ 2021 年の上位の球種でも、中身が違う](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_7_ja.png)

Adam Wainwright のシンカーは、2021 年の +20 点のうち +13 点が打球の運でした。空振り率は 9.8% で、この年のシンカーの平均（15.5%）より低めです。2022 年は運が +11 点とまだプラスでしたが、打球の質が −18 点まで下がり、合計は 0 点でした。

Corbin Burnes のカッターは、2021 年は打球の運がむしろマイナス（−7 点）で、三振・四死球と打席途中の球だけで +34 点ありました。2022 年はこの 2 つが +26 点に減りましたが、今度は運が +11 点に振れ、打球の質が −10 点だったので、合計は +27 点です。

1 つの球種の 1 年だけを見ると、運のように続きにくい部分も、たまたま続いたり続かなかったりします。選んだ 2 つの例で何かが言えるわけではないので、全部の球種でも見てみます。

### 全部の球種で見ると

2 シーズンとも 400 球以上投げた組（1,962 組）で、100 球あたりの値から球種の平均を引いて計算しました。

![run value の内訳](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_3_ja.png)

1 年の run value のばらつきを 5 つに分けた取り分です（ある部分と run value 全体の共分散 ÷ run value の分散。5 つを足すと 100% になります）。打球の運が 27%、走者・アウトの状況が 4% で、合わせて 3 割ほどあります。

![打球の運と状況は、翌年にほぼ続かない](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_4_ja.png)

それぞれの部分だけを取り出して、今年と翌年の相関を取りました。打球の運（0.06）と状況（−0.03）は、翌年にほとんど続いていません。逆に、三振・四死球（0.57）と打席途中の球（0.60）はよく続きます。この 2 つは 1 年のばらつきの中では合わせて 3 割ほどしかありませんが、「今年高い球種は翌年も高い」という結びつきの 7 割ほどは、ここから来ていました。

## 運と状況を除くと、翌年がよく当たる

それなら、続きにくい運と状況を除いた残りの 3 つを足せば、翌年の run value をよりよく当てられるのではないか、と考えて試しました。当てる式は 2 年目が 2021 年までの組で決め、2 年目が 2022 年以降の組で確かめています（式を決めるのに使っていない年で確かめるためです）。

![運と状況を除くと、翌年の run value がよく当たる](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_carryover_5_ja.png)

運と状況を除いて足しただけで、今年の run value をそのまま使うより翌年との相関が高くなりました（0.29 → 0.35）。投手を単位に組を選び直して 2,000 回計算すると、この差の 95% 区間は 0.03〜0.10 で、0 を含みませんでした。100〜399 球の組でも同じ向き（0.12 → 0.18）でしたが、どちらも低い値です。

## まとめ

今回のデータでは、次のような結果になりました。

- 空振り率は翌年との相関が高く（500 球で 0.68）、約 100 球で 1 年の数字の半分が実力（偶然でない部分）になる
- run value は 1 年分だと翌年との相関が低く、500 球で 0.20、先発の主な球種 1 年分（約 1,100 球）でも 0.35
- run value の 1 年のばらつきの 3 割ほどは、打球の運と走者・アウトの状況で、翌年にほとんど続かない
- 運と状況を除いた 3 つを足すと、翌年の run value がよく当たる（0.29 → 0.35）

1 年分の run value を見るときは、空振り率や三振・四死球のような翌年に続きやすい数字も一緒に見ると、翌年の見込みを考えやすくなりそうだ、というのが個人的な感想です。

## 付録

**用語**

- 空振り率：スイングした球のうち空振りの割合
- 被 xwOBA：その球種で終わった打席の結果を、出塁・長打の価値で表したもの。打球は、実際にヒットになったかではなく、打球の速さと角度から見た期待値に置き換えています
- run value：1 球ごとに、その球で得点の見込みがどれだけ動いたかを足したもの（プラスほど投手に有利）

**注意点**

- 相関には「数字の偶然のぶれ」と「球種そのものが変わった（握りを変えた、球速が落ちた等）」の両方が入っています
- 球数は 2 シーズンのうち少ないほうで分けているので、同じ帯の中に片方の年だけ多く投げている組も混ざります
- 2020 年（60 試合の短縮シーズン）を含む組も入れています
- 成績が落ちて翌年に登板しなくなった（または 100 球未満になった）投手は組になりません。1 年目の低い側が抜けるので、相関はやや低めに出ている可能性があります
- Savant の球種別の表ではナックルカーブとスローカーブがカーブにまとめられているので、1 球ごとのデータもそれに合わせています
- 「打球の運」は、打球の速さと角度、カウントから見込まれる値との差として計算しただけで、守備や球場の影響などを分けてはいません
- 5 つへの分け方は、今回自分で決めたものです。たとえば打球の見込みにカウントを使うかどうかで、「質」と「運」の境目は少し動きます

**集計**

前半の相関は dbt で作っていて、同じ表を別の書き方で計算し直すテストを付けています。run value を分けた部分は、1 球ごとのデータから pandas で計算しています。
