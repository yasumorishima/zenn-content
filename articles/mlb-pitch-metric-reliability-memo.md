## きっかけ

Baseball Savant で投手の球種ごとの成績を眺めていて、ふと気になったことがあります。「去年よく空振りを取れていた球種は、今年も取れているのだろうか」「去年よく抑えた球種は、今年もよく抑えているのだろうか」。

去年の数字が良かったのは、その球種が良いからなのか、たまたまそういう年だったからなのか。指標によって、そのあたりの事情は違いそうです。そこで、MLB の公開データで次のことを調べてみました。

> ある投手のある球種について、今年の成績と、翌年の同じ投手・同じ球種の成績は、どれくらい似ているか。
> それは指標（空振り率、run value など）によってどれくらい違うか。

私は野球の現場の経験者ではなく、公開データを集計してみただけです。そのつもりで読んでいただければと思います。

## 使った指標

Baseball Savant（MLB の Statcast データを公開しているサイト）には、投手ごと・球種ごとに次のような数字が載っています。今回はこの 5 つを見ました。

| 指標 | 意味 |
|---|---|
| 使用率 | その投手が投げた球のうち、その球種が占める割合 |
| 空振り率 | 打者がスイングしたうち、空振りだった割合 |
| 被 xwOBA | その球種で終わった打席の結果を、出塁・長打の価値で表したもの。打球については、実際にヒットになったかではなく、打球の速さと角度から見た期待値に置き換えている（三振・四球などはそのまま） |
| 強い打球の割合 | 打たれた打球のうち、打球速度が 95 マイル（約 153 km/h）以上だった割合 |
| run value / 100 球 | その球種を投げた結果、失点をどれだけ防いだか（増やしたか）を得点に換算し、100 球あたりにしたもの。ストライク・ボール、ヒット・アウトなど 1 球ごとの結果を足し合わせている。今回のデータではプラスほど投手にとって良い |

run value は球種の成績を 1 つの数字にまとめたものなので、見る機会が多い数字だと思います。

## 調べ方

### 「翌年との相関」を見る

同じ投手・同じ球種を、続く 2 シーズンで 1 組にして並べます。たとえば「ある投手のスライダーの 2023 年」と「同じ投手のスライダーの 2024 年」で 1 組です。こうした組をたくさん集めて、1 年目の値と 2 年目の値の相関を取りました。

- 相関が 1 に近い：今年良かった球種は、翌年もだいたい同じくらい良い
- 相関が 0 に近い：今年良かったかどうかと、翌年の成績にはほとんど関係がない

### 球種ごとの平均を引いてから比べる

スライダーはもともと空振りが多く、シンカーは少ない、というように、球種によって数字の水準がかなり違います。そのまま相関を取ると、「スライダーは毎年スライダーなので空振りが多い」という球種の違いだけで相関が高く出てしまいます。

見たいのは「スライダーの中で、この投手のスライダーは良い方か」が翌年も続くかどうかなので、その年のその球種の平均を引いた値（たとえば「スライダー全体の平均より空振り率が何ポイント高いか」）で相関を取りました。

### 球数で分ける

投げた球数が少ないと、数字は偶然でぶれやすくなります。そこで組を、2 シーズンのうち少ない方の球数で 4 つに分けました。目安として、100〜199 球は中継ぎ投手の 3 番目の球種くらい、800 球以上は先発投手の主な球種くらいの量です。

### データ

- Baseball Savant の球種別成績、2017〜2025 年。自分で公開しているデータセット（Hugging Face `yasumorishima/mlb-stats` の `marts/mart_scouting_reliability`）から計算しました
- どちらの年も 100 球以上投げた組だけを使い、全部で 8,022 組です
- 進行中の 2026 年は入れていません

使用率の相関が高いのは、投手が球種の配分を年ごとに大きく変えないためだと思われます。良し悪しの指標ではないので、参考として載せています。

### 上位 20% が翌年も上位 20% に入る割合

相関の数字だけだとイメージしにくかったので、別の形でも数えてみました。球種の平均を引いた値を各年の中で並べ、良い方から上位 20% に入った球種が、翌年も上位 20% に入っていた割合です（被 xwOBA は低いほど良いとして並べています）。今年と翌年がまったく無関係なら、この割合は 20% くらいになるはずです。

| 指標 | 100 球以上の全組 | 400 球以上の組 |
|---|---|---|
| 空振り率 | 52% | 58% |
| 被 xwOBA | 37% | 41% |
| run value / 100 球 | 29% | 32% |

400 球以上の球種で見ると、run value で上位 20% に入った球種のうち、翌年も上位 20% だったのは 3 つに 1 つくらいで、36% は翌年下半分でした。空振り率では、翌年も上位 20% だったのが 58%、下半分だったのは 12% でした。

### run value が似にくい理由（推測）

ここは今回きちんと調べていないので、推測です。run value は 1 球ごとの結果を得点に換算して足し合わせているので、打球がヒットになったかアウトになったか、といった投手だけでは決まらない部分も含みます。空振り率は「スイングして空振りしたか」だけを数えるので、そうした部分が入りにくいのかもしれません。被 xwOBA が両者の間に来るのも、打球については「ヒットになったか」を外して打球の速さと角度で見ているからではないか、と考えています。

## まとめ

今回のデータでは、空振り率は翌年と比較的よく似ていて、run value は 1 年分だとあまり似ていない、という結果になりました。1 年分の run value を見るときは、空振り率や被 xwOBA も一緒に見たり、複数年を合わせたりするとよさそうだ、というのが個人的な感想です。

## 注意点

- 相関には「数字の偶然のぶれ」と「球種そのものが変わった（握りを変えた、球速が落ちた等）」の両方が入っています。1 シーズンの数字がどれだけ正確か、を表すものではありません
- 800 球以上の組は 401 と少なめです
- 球数は 2 シーズンのうち少ない方で分けているので、同じ帯の中に片方の年だけ多く投げている組も混ざります。また、帯によって先発と中継ぎの割合なども違うので、帯の間の差には球数以外の違いも入っています
- 2020 年（60 試合の短縮シーズン）を含む組も入れています
- 成績が落ちて翌年に登板しなくなった投手は組になりません。この偏りは補正していません
