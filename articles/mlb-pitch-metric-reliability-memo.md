## きっかけ

Baseball Savant で投手の球種ごとの成績を眺めていて、ふと気になったことがあります。「ある年によく空振りを取れていた球種は、翌年も取れているのだろうか」「ある年によく抑えた球種は、翌年もよく抑えているのだろうか」。

ある年の数字が良かったのは、その球種が本当に良いからなのか、たまたまそういう年だったからなのか。指標によって、そのあたりの事情は違いそうです。そこで、MLB の公開データで次のことを調べてみました。

> ある投手のある球種について、今年の成績と翌年の成績（同じ投手・同じ球種）には、どれくらい関係があるか。
> その関係の強さは、指標（空振り率、run value など）によってどれくらい違うか。

私は野球の現場の経験者ではなく、公開データを集計してみただけです。そのつもりで読んでいただければと思います。

## 使った指標

Baseball Savant（MLB の Statcast データを公開しているサイト）には、投手ごと・球種ごとに次のような数字が載っています。今回はこのうち 5 つを主に見ました。

| 指標 | 意味 |
|---|---|
| 使用率 | その投手が投げた球のうち、その球種が占める割合 |
| 空振り率 | 打者がスイングした球のうち、空振りだった割合 |
| 被 xwOBA | その球種で終わった打席の結果を、出塁・長打の価値で表したもの。打球については、実際にヒットになったかどうかではなく、打球の速さと角度から見た期待値に置き換えている（三振・四球などはそのまま） |
| 強い打球の割合 | 打たれた打球のうち、打球速度が 95 マイル（約 153 km/h）以上だった割合 |
| run value / 100 球 | その球種を投げた結果、失点をどれだけ防いだか（あるいは増やしたか）を点数に換算し、100 球あたりにしたもの。ストライク・ボール、ヒット・アウトなど 1 球ごとの結果を足し合わせている。今回のデータでは値が大きいほど投手にとって良い |

run value は球種の成績を 1 つの数字にまとめたものなので、目にする機会が多い数字だと思います。

## 調べ方

### 翌年との相関を見る

同じ投手・同じ球種の、連続する 2 シーズンを 1 組にします。たとえば「ある投手のスライダーの 2023 年」と「同じ投手のスライダーの 2024 年」で 1 組です。こうした組をたくさん集めて、1 年目の値と 2 年目の値の相関を取りました。

- 相関が 1 に近い：今年良かった球種は、翌年もだいたい同じくらい良い
- 相関が 0 に近い：今年良かったかどうかと、翌年の成績にはほとんど関係がない

### 球種ごとの平均を引いてから比べる

スライダーはもともと空振りが多く、シンカーは少ない、というように、球種によって数字の水準がかなり違います。そのまま相関を取ると、「スライダーはどの投手が投げても空振りが多い」という球種の違いだけで相関が高く出てしまいます。

見たいのは「スライダーの中で、この投手のスライダーは良いほうか」が翌年も続くかどうかなので、その年のその球種の平均を引いた値（たとえば「スライダー全体の平均より空振り率が何ポイント高いか」）で相関を取りました。

### 球数で分ける

投げた球数が少ないと、数字は偶然でぶれやすくなります。そこで組を、2 シーズンのうち少ないほうの球数で 4 つの帯に分けました。目安として、100〜199 球は中継ぎ投手の 3 番目の球種くらい、800 球以上は先発投手の主な球種くらいの量です。

### データ

- Baseball Savant の球種別成績、2017〜2025 年。自分で公開しているデータセット（Hugging Face `yasumorishima/mlb-stats` の `marts/mart_scouting_reliability`）から計算しました
- どちらの年も 100 球以上投げた組だけを使い、全部で 8,022 組です
- 進行中の 2026 年は入れていません

## 結果

結果を図と表にまとめました。

![同じ投手・同じ球種の翌年との相関](https://raw.githubusercontent.com/yasumorishima/mlb-data-pipeline/master/docs/images/pitch_metric_yoy_ja.png)

| 指標 | 100〜199 球 | 200〜399 球 | 400〜799 球 | 800 球以上 |
|---|---|---|---|---|
| 使用率 | 0.79 | 0.81 | 0.87 | 0.84 |
| 空振り率 | 0.53 | 0.63 | 0.70 | 0.74 |
| 被 xwOBA | 0.26 | 0.34 | 0.46 | 0.53 |
| 強い打球の割合 | 0.20 | 0.28 | 0.38 | 0.43 |
| run value / 100 球 | 0.09 | 0.17 | 0.25 | 0.35 |
| 組の数 | 3,063 | 2,997 | 1,561 | 401 |

気づいたことを書いておきます。

- 使用率を除くと、どの指標も球数が多いほど翌年との相関が高くなりました。球数が少ないほど偶然のぶれが大きいので、ここは予想どおりでした
- 指標による違いは、球数による違いよりも大きく出ました。100〜199 球の組の空振り率（0.53）のほうが、800 球以上の組の run value（0.35）より翌年との相関が高くなっています
- run value は、800 球以上の組でも 0.35 でした。今回のデータでは、今年の run value と翌年の run value の関係は弱い、という結果です

使用率の相関が高いのは、投手が球種の配分を年ごとに大きく変えないためだと思われます。良し悪しの指標ではないので、参考として載せています。

### 上位 20% が翌年も上位 20% に入る割合

相関の数字だけだとイメージしにくかったので、別の形でも数えてみました。球種の平均を引いた値を各年の中で並べ、良いほうから数えて上位 20% に入った球種が、翌年も上位 20% に入っていた割合です（被 xwOBA は低いほど良いとして並べています）。今年と翌年がまったく無関係なら、この割合は 20% くらいになるはずです。

| 指標 | 100 球以上の全組 | 400 球以上の組 |
|---|---|---|
| 空振り率 | 52% | 58% |
| 被 xwOBA | 37% | 41% |
| run value / 100 球 | 29% | 32% |

400 球以上の組で見ると、run value で上位 20% に入った球種のうち、翌年も上位 20% だったのは 3 つに 1 つくらいで、36% は翌年は下半分まで下がっていました。空振り率では、翌年も上位 20% だったのが 58%、下半分まで下がったのは 12% でした。

## まとめ

今回のデータでは、次のような結果になりました。

- 空振り率は、翌年との相関が比較的高い
- run value は、1 年分だと翌年との相関が低い

なぜ run value が翌年に続きにくいのかは、run value の計算方法を確かめたうえで調べて、追記する予定です。

## 注意点

- 相関には「数字の偶然のぶれ」と「球種そのものが変わった（握りを変えた、球速が落ちた等）」の両方が入っています。1 シーズンの数字がどれだけ正確かを表すものではありません
- 800 球以上の組は 401 組と少なめです
- 球数は 2 シーズンのうち少ないほうで分けているので、同じ帯の中に片方の年だけ多く投げている組も混ざります。また、帯によって先発と中継ぎの割合なども違うので、帯の間の差には球数以外の違いも入っています
- 2020 年（60 試合の短縮シーズン）を含む組も入れています
- 成績が落ちて翌年に登板しなくなった（または 100 球未満になった）投手は組になりません。この偏りは補正していません
