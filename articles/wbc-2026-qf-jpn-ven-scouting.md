## 作ったもの

WBC 2026 準々決勝・日本 vs ベネズエラ戦に特化したスカウティングダッシュボードです。

**アプリ**: [https://wbc-qf-jpn-ven.streamlit.app/](https://wbc-qf-jpn-ven.streamlit.app/)
**GitHub**: [https://github.com/yasumorishima/wbc-scouting](https://github.com/yasumorishima/wbc-scouting)

1次ラウンドでは各チーム単位の打者・投手ダッシュボード（全20チーム30アプリ）を作りましたが、準々決勝は対戦カードが確定しています。「この打者にはどの球種が有効か」「この投手のどのゾーンが被打率が高いか」を1アプリで見られるようにしました。

## 5タブ構成

### 🎯 タブ1: 対戦プレビュー

![予想スタメンテーブル](/images/wbc-qf-lineup-table.png)

ベネズエラの予想スタメン9人のテーブル、マチャド（NPB所属）の注意書き、控え・代打候補テーブルが並びます。

各打者をexpanderで展開すると、1人あたり以下のデータが全て表示されます。

- 主要指標6つ（AVG/OBP/SLG/OPS/K%/BB%）とMLB平均との比較
- レーダーチャート（5軸、MLB平均ライン付き）
- ゾーンヒートマップ（3×3・5×5）— 打率・xwOBAのゾーン別分布、vs左投手/vs右投手で分割
- スプレーチャート — vs左投手/vs右投手で分割

![スプレーチャート（左右投手別）](/images/wbc-qf-spray-chart.png)
- 左右投手別成績（OPS/打率/K%/BB%を並列表示）
- 配球プラン — 全体 + vs左投手 + vs右投手の3パターン。球種別空振率、ゾーン別打率、カウント別OPS、左右スプリットから自動生成
- 守備シフト推奨 — 打球方向・ゴロ率・打球速度から内野・外野の配置を自動生成、左右投手別に表示
- 球種別パフォーマンステーブル（打率・長打率・空振率・チェイス率）
- カウント別パフォーマンス（有利=緑・不利=赤・イーブン=琥珀で色分け）

タブの最後に先発投手（Ranger Suárez・左腕）の分析セクションがあり、打撃アプローチ（左打者として/右打者として）、球種構成、変化量チャート、配球ヒートマップ、左右打者別成績、カウント別球種選択をexpander内で展開できます。

### 📋 タブ2: ゲームプラン

試合のフェーズ別にStatcastデータをまとめたタブです。

![チーム弱点分析](/images/wbc-qf-weakness-analysis.png)

- **チーム弱点分析** — K% ≥ 22.4%（MLB平均）の打者、BB% < 8.3%の打者、左右別OPSに80pts以上の差がある打者を自動抽出し、選手名と数値を一覧表示
- **1〜3回 vs スアレス（先発）** — 打撃戦略: 先発のK%/BB%/Whiff%/平均球速・球種配分。投球戦略: 打順グループ別（#1-3/#4-6/#7-9）に各打者のAVG/K%/BB%を表示
- **4〜5回（2巡目 or 中継ぎ移行）** — 打撃戦略: 中継ぎ投手のK%/BB%/Whiff%/球速。投球戦略: 2巡目のMLB統計傾向（被OPSが15-20%上昇）と三振率・四球率別の打者分類
- **6回以降（勝ちパターン）** — 打撃戦略: 各リリーフのK%/Whiff%/Chase%/球速と特徴分類（奪三振型/四球型等）。投球戦略: 左右別OPSに差がある打者のマッチアップデータ、打者別成績一覧
- **代打候補** — 控え選手のAVG/OPS/K%

全てのテキストはMLB Statcastの数値のみで構成しています。「攻めろ」「粘れ」のようなコーチング口調は入れず、データだけを提示する方針です。

### ⚔️ タブ3: 打線スカウティング

タブ冒頭にチーム打線のレーダーチャート（AVG/OBP/SLG/K%/BB%の5軸、MLB平均ライン付き）。その下に全打者のロスターテーブルとドロップダウンで選手を選んでの個別分析（指標表示・スカウティング要約・配球プラン・守備シフト・レーダーチャート・ゾーンヒートマップ・スプレーチャート等）。

### 🎱 タブ4: 先発投手分析

予想先発Ranger Suárezの投球データです。指標カード（平均球速・平均回転数・空振率・チェイス率・決め球率・被打率等）、スカウティング要約に加え、以下のexpanderで深掘りできます。

- 打撃アプローチ（左打者として/右打者として）
- 球種テーブル（球速 mph/km/h 両表記・変化量・空振率・決め球成功率）+ 変化量チャート
- 配球ゾーンヒートマップ + 左右打者別成績
- カウント別球種選択（ドーナツチャート）+ カウント別パフォーマンス

![カウント別球種選択](/images/wbc-qf-pitch-selection.png)

### 🔥 タブ5: ブルペン分析

ブルペンの概要（全リリーフのERA・K%・球速等を一覧表示）と、ドロップダウンで個別投手を選んでの詳細分析。構成はタブ4と同じ（指標カード・スカウティング要約・打撃アプローチ・球種構成・ヒートマップ・カウント別分析）。

## 技術的なポイント

### 分析テキストの動的生成

`generate_pitching_plan()`や`generate_hitting_plan()`等の関数がStatcastの生データから打者・投手ごとの分析テキストを自動生成します。球種別の空振率、ゾーン別打率、カウント別OPS、左右スプリット等を計算し、閾値を超えた項目だけをテキスト化します。

```python
# 例: 球種別の被打率が最も高い球種を特定
hittable = sorted(
    [p for p in pt_stats if p["ba"] is not None],
    key=lambda x: x["ba"], reverse=True
)
if hittable and hittable[0]["ba"] >= 0.250:
    h = hittable[0]
    lines.append(
        f"- **被打率が最も高い球種:** {h['label']}"
        f"（被打率 .{int(h['ba']*1000):03d}）"
    )
```

同様の関数が6つあり、打者のスカウティング要約（`generate_player_summary`）、投手のスカウティング要約（`generate_pitcher_summary`）、配球プラン（`generate_pitching_plan`）、打撃アプローチ（`generate_hitting_plan`）、守備シフト推奨（`generate_defensive_positioning`）、先発投手の球種分析（`generate_sp_pitch_analysis`）をそれぞれStatcastデータから動的に生成します。

### 全指標にMLB平均値を並記

SLG .476 だけでは「高いのかどうか」がわかりません。全ての数値にMLB平均を添えることで、その選手の立ち位置が一目で判断できます。

```
K% 28.3% (MLB avg 22.4%)
BB% 6.1% (MLB avg 8.3%)
```

### ゾーン名の打席側自動反転

左打者と右打者では「インコース」「アウトコース」が逆になります。`_zone_names_for_bats()`で打席に応じてゾーン名を自動反転し、「インコース高め」等の表記が常に正しくなるようにしています。

### 用語解説の設計

全ての指標の横に **?** アイコン（Streamlitの`help`パラメータ）があり、ホバーすると意味とMLB平均値が表示されます。xwOBAのような指標もその場で理解できます。カウント表記も「ボール数-ストライク数」の読み方ガイドと色凡例（🟢打者有利 🔴打者不利 🟡イーブン）付きです。
