## はじめに

前回の記事で、NPB予測にベイズ統合を導入しました。

https://zenn.dev/shogaku/articles/npb-bayes-integration-production

8年間のバックテストで「97%の確率でMarcel法を上回る」という結果を紹介しましたが、それは**平均的な話**です。一番外れた年にベイズはどうだったのか？

NPB予測史上最大の「番狂わせ」だった**2021年**で検証しました。今回は**25人の新外国人選手全員のMLB/KBO成績をFanGraphs・Baseball Savantから個別取得**し、外国人個別予測も含めたフル検証です。

- **ヤクルト**: 2020年最下位 → 2021年セ・リーグ優勝
- **オリックス**: 2020年最下位 → 2021年パ・リーグ優勝

→ **GitHub**: https://github.com/yasumorishima/npb-2021-backtest
→ **予測モデル本体**: https://github.com/yasumorishima/npb-prediction

## 用語

| 用語 | 意味 |
|---|---|
| **Marcel法** | 過去3年の成績を重みづけ平均して翌年を予測 |
| **ベイズ統合** | Marcel 35% + Stan/Ridge補正 40% + ML 25%の混合モデル |
| **外国人個別予測** | MLB/KBO成績からStan v2でNPB成績を推定 |
| **OPS** | 出塁率＋長打率。打者の総合力 |
| **ERA** | 防御率。投手が9回投げたら何点取られるか |
| **wOBA** | 加重出塁率。打撃の総合力をより正確に測る |
| **MAE** | 平均絶対誤差。予測のズレの平均。小さいほど良い |

### わかったこと

**「平均的な選手」は当たる。「極端な選手」は外れる。**

- **クロン**: OPS .703予測 vs .701実績（誤差.002）。MLB wOBA .321はリーグ平均付近で、ベイズ回帰が自然に効いた
- **オスナ**: .683 vs .694（誤差.011）。同様にMLB平均的な打者
- **サイスニード**: ERA 3.53 vs 3.41（誤差0.12）

一方：

- **ガーバー**: MLB wOBA .127（歴史的に悪い）→ OPS .862予測 → 実績.352。モデルが「ここまで悪い選手はいないはず」と平均方向に引っ張りすぎた
- **スパークマン/バルガス**: MLB ERA 5-6台 → NPB 3-4台と予測 → 実績6-11台。「NPBならMLBより良くなる」と過度に楽観視

## 前年1位チームはなぜ崩壊したか

### 巨人（予測84.3勝 → 実際61勝、-23.3勝の大外れ）

| 選手 | 2020年 | 2021年 | 変化 |
|---|---|---|---|
| 菅野智之 | ERA 1.97 | ERA 3.19 | **+1.22** |

菅野・坂本・丸の主力3人が揃って劣化。ベイズ補正はこの3人のスキル指標を高く評価していたため、Marcelより高い84.3勝を予測してしまった。

### ソフトバンク（予測76.2勝 → 実際60勝）

千賀の投球回減少（121IP→84IP）と柳田の打撃劣化（OPS .959→.812）がチーム崩壊の原因。

## 知見まとめ

### 1. ベイズ回帰の「平均回帰しすぎ」問題

極端な前リーグ成績を持つ外国人選手で、モデルが平均方向に引っ張りすぎる。ガーバー（wOBA .127 → OPS .862予測 → 実績.352）が典型例。改善案: 極端な値への回帰に上下限を設ける。

### 2. MLB直近1年の小サンプル問題

サンタナは2020年MLBで84PA（コロナ短縮）のwOBA .271で予測したが、MLB通算OPS .757を考慮していれば精度が上がった可能性がある。改善案: 直近1年だけでなく通算成績も加重平均。

### 3. MLBで悪い投手はNPBでも悪い

スパークマン（6.02→3.88予測→6.88実績）、バルガス（5.03→3.89→11.00）。モデルが「NPBならMLBより活躍できる」と楽観視しすぎ。改善案: MLB ERA下位の投手への下限設定。

### 4. 順位変動の原因は外国人ではなく日本人

2021年は杉本・宮城・山田復活・菅野劣化など、日本人選手のブレイク/劣化が順位を決めた年。外国人個別予測の効果は+0.3勝（MAE悪化方向）にとどまった。

### 5. 予測できなかったが、モデルは「正直」だった

ヤクルト優勝確率0.1%、オリックス0.0%は「外れた予測」だが、「過去のデータからはこう計算される」という正直な回答でもある。過去に例がほぼない事象に低い確率を出すのは、モデルとして正しい挙動。

## 結論

外国人個別予測は「平均的なMLB選手」の精度を上げるが、「極端な選手」で大外れするリスクがある。2021年は日本人選手の予測不可能な変動が順位を決めた年であり、外国人個別予測のインパクトは限定的だった。

なお、このプロジェクトは個人の趣味プロジェクトであり、データの取得・検証プロセスに見落としがある可能性があります。予測結果は参考程度にご覧ください。
